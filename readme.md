# 📬 LaraMail-Architect
A high-performance Laravel utility to generate dynamic PDFs and dispatch automated emails with advanced routing (CC/BCC) and custom HTML templates.

---

### 🌟 Key Capabilities
1. **Dynamic HTML Templates**: Send beautifully designed, brand-focused emails by injecting data into custom HTML layouts.
2. **Advanced Routing**: Full support for Multiple Users, CC, and BCC for complex corporate communications.
3. **Instant PDF Engine**: Generate professional PDFs on the fly—ready for instant download or as secure email attachments.
4. **Plug-and-Play**: Optimized for seamless integration into any Laravel-based SaaS or ERP system.

### 🛠️ Technical Stack
1. **Backend**: PHP 8.4 & Laravel 11.x.
2. **Frontend**: Bootstrap 5 & jQuery for real-time interactions.
3. **Infrastructure**: SMTP/Mailgun ready with optimized PDF rendering.

---

### 🚀 Quick Start
1. **Clone & Install**: `composer install`.
2. **Environment**: Update `.env` with SMTP/Mail credentials.
3. **Migrate & Run**: `php artisan migrate` then `php artisan serve`.
